🛠️ Технологии
Python 3.11+ - основной язык

pytest - фреймворк для тестирования

requests - HTTP-запросы к API

allure-pytest - создание отчетов

pytest-dependency - управление зависимостями тестов

📦 Установка и запуск
1. Клонирование репозитория
bash
git clone <repository-url>
cd qa-python-Diplom2
2. Установка зависимостей
bash
pip install -r requirements.txt
3. Запуск тестов
bash
# Все тесты
pytest

# С генерацией Allure отчетов
pytest --alluredir=allure-results

# Просмотр отчета
allure serve allure-results
4. Запуск конкретных тестов
bash
# Только тесты пользователей
pytest tests/test_create_user.py -v

# Тесты с определенной меткой
pytest -m "smoke" -v
📊 Генерация отчетов
Проект использует Allure для создания детальных отчетов:

bash
# Генерация отчетов
pytest --alluredir=allure-results

# Просмотр в браузере
allure serve allure-results

# Генерация статического отчета
allure generate allure-results -o allure-report
🔧 Конфигурация
Переменные окружения
Создайте файл .env для настройки:

env
BASE_URL=http://localhost:8080/api
TEST_TIMEOUT=30
LOG_LEVEL=INFO
Структура тестовых данных
Тестовые данные организованы в классах:

DataUser - данные пользователей

ExpectedResponses - ожидаемые ответы API

StatusCodes - HTTP статус-коды
